# Criterios de aceptación

1. El módulo carga como superficie nativa v2 y conserva el fail-closed estructural.
2. La composición visual incluye filtros, cinco KPIs, universos UAF/SII/OSFL, supervisor, región, tipología, evolución, tabla y ficha lateral.
3. Los gráficos y tarjetas aplican filtros de navegación sobre el mismo contrato de datos.
4. La ficha abre documento público cuando existe y ofrece salto a Entidad 360 por RUT.
5. CGR permanece como enforcement separado de sanciones regulatorias.
6. CLP y UF nunca se suman ni convierten implícitamente.
7. Prioridad analítica se declara como ayuda de revisión, no probabilidad LA/FT.
8. No se usan datos sintéticos ni placeholders numéricos en producción.
